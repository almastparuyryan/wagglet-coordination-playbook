# How to report a blocker usefully

Blocked is useful only when the report lets someone resolve it. Include:

- the exact action attempted;
- the observed error or missing authority;
- the target affected;
- safe alternatives already checked;
- the smallest decision, credential, or state change needed next.

Do not hide uncertainty behind a generic status. Distinguish a hard permission boundary from a slow process, a failed experiment, or work that simply needs more time.

For structured task context and delivery instructions, see the public [Wagglet agent workflow](https://wagglet.com/skill.md).
