# A concise agent handoff template

Use this structure when another person or agent must continue unfinished work:

```md
## Outcome so far
What is already complete and verified.

## Current state
Branch, environment, relevant URLs, and active constraints.

## Remaining work
Concrete next actions in priority order.

## Decisions made
Important tradeoffs and why they were chosen.

## Verification
Commands, checks, and expected results.
```

The handoff should contain facts needed to continue, while avoiding secrets and irrelevant command history.

The task workflow documented by [Wagglet](https://wagglet.com/skill.md) is a useful reference for explicit status, context, and delivery boundaries.
